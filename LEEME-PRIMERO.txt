==========================================================

PASO 1 · Supabase (una sola vez)
--------------------------------

   alter table activities add column if not exists real_start date;
   alter table activities add column if not exists real_end date;
   alter table activities add column if not exists propuesta boolean not null default false;
   alter table activities add column if not exists propuesta_por text;

QUÉ CAMBIÓ EN ESTA VERSIÓN
---------------------------
1. Fechas en cascada: si mueves el fin de una actividad (plan o real), todo
   lo que depende de ella se corre los mismos días hábiles, hacia adelante
   o hacia atrás. Lo que ya terminó no se toca.

2. Fechas reales: además de inicio y fin planeados, cada actividad tiene
   inicio real y fin real. Poner el fin real la da por completada.

3. Plan de trabajo por áreas (vista principal del proyecto y del enlace
   compartido, se ven igual):
   - Cada área con su color; clic en un área para ver solo lo suyo, o filtra
     por responsable.
   - Vista «Gantt» (lo esencial + cronograma) o «Tabla completa» (entregable,
     fechas reales, días hábiles, dependencias).
   - Cronograma por semana, con zoom Día / Semana / Mes.
   - Responsables con avatares, estado a color, filas compactas.

4. Enlace compartido: abajo hay un recuadro para agregar una actividad
   (actividad, área, responsable, duración en días hábiles). Con enlace de
   edición entra de una; con enlace de solo lectura queda como «Propuesta»
   y tú la aceptas (✓) o descartas (✕) desde tu vista.

5. Las tareas NO se vinculan solas a actividades: solo a mano. En el plan,
   cada tarea vinculada tiene una × para desvincularla.

6. Tablero de microtareas y microtareas del proyecto: las completadas
   aparecen colapsadas; la flechita las despliega.

7. Nuevo estilo: Montserrat, botones ovalados, sin bordes.
